# 离线地图

[English](OFFLINE_MAPS.en.md) · [矢量绘制与主机测试](LEAN_VECTOR_MAP.md)

## 使用方式与边界

在 APP「我的 → 离线地图」搜索并下载地区道路数据。手机保存 RVS1 几何数据，按当前路线生成有界 RVP1 窗口，必要时以 RVZ1 压缩传输。仪表不保存整座城市，不生成地图图片，也不包含字体或样式资源。地图缓存不提供独立离线算路；目的地搜索、规划和偏航重算仍由手机服务负责。

连接车辆 Wi-Fi 后保持 APP 前台，等待当前路线的设备地图就绪。视频可用时优先显示实时视频；视频停止时绘制已确认的道路窗口、路线和真实位置。没有完整窗口时仍可显示有效路线与位置，但必须保留未就绪状态。首次下载、后台骑行、锁屏、窗口更新和实际 LCD 效果需在目标手机与终端上验证。

## 板端接入

使用 **SDK 1.0.0 / revision 27 / FreeRTOS ABI 8 或更新的匹配包**，头文件、静态库与元数据必须成套导入。地图接在完整 P4 根工程，独立 managed 示例不应并发调用它的私有核心实例或启动第二个终端来复用地图。

| 文件 | 职责 |
| --- | --- |
| `route_map_transport.c` | TCP 5003、认证 TLS、超时和取消 |
| `route_map_store.c` | 有界暂存、当前导航/路线/位置、有效期与显示切换 |
| `route_vector_store.c` | worker 校验、不可变快照、短锁和引用计数 |
| `route_map_compression.c` | RVZ1 解压、长度和 CRC 校验 |
| `route_vector_view.c` | RGB565 道路、路线和箭头绘制，缺块状态传播 |

```c
#include "route_map_store.h"
cfg.map = terminal_map_port();
cfg.route_navigation = cfg.map.max_bytes != 0;
```

SDK 所有者线程将当前 Wi-Fi 主业务实例的认证事件转发给 `terminal_map_event`，并周期调用 `terminal_map_poll`。显示任务使用 `terminal_map_draw`；保存事件前复制回调数据。地图就绪不由视频 UDP 5001 的状态推断。TLS 授权来自当前业务会话，不记录凭据或使用通用固定密钥。

## 传输、内存与恢复

只接受 RVP1/RVZ1 矢量窗口，单窗口上限 1 MiB；没有 JPEG 地图缓存或栅格回退。收满后校验 SHA、导航/路线/窗口身份、解析预算和压缩长度，再发布快照并确认就绪。可确认的空块属于覆盖，缺失块不属于覆盖。协议仍使用连续 TCP/TLS 传输；断线续传位置以终端确认值为准。

校验失败保留可用快照。位置过期后冻结最后真实位置并将箭头变灰，不外推位置。导航结束、owner 或会话切换须清理旧状态并拒绝迟到结果。地图未就绪时检查 TCP 5003、TLS、数据覆盖、窗口身份与剩余内存，不用构建通过推断设备运行成功。

地图来源和许可信息在 APP 的「地图来源」中展示，仪表不重复叠加。接入方应保留实际数据来源和随数据交付的许可说明。
